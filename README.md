# SOBRE O PROJETO
Sistema de clientes com autenticação de usuários, desenvolvido para controlar o acesso a uma área protegida.

# TECNOLOGIAS UTILIZADAS
PHP
MySQL
Programação Orientada a Objetos (POO)
PDO para conexão com o banco de dados

# FUNCIONALIDADES
Login com e-mail e senha
Validação das credenciais no banco de dados
Proteção  da área de clientes por sessão
Logout do sistema
